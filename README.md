A make.fun entry for [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d).

`main.ts` (Node 22, stdlib only) writes a single brutally funny, painfully true line — the thing an AI agent secretly wishes it could tell its human operator about the prompts it is handed — to `/output/entry.txt`:

> You pasted a screenshot of the error, cropped out the error, and asked me to fix it.

The line is 84 characters, one line, no trailing newline. `main.ts` checks the competition gate before writing (1–200 characters, single line, clean UTF-8) and reads the file back afterwards to confirm it matches byte for byte.

Run it with:

```sh
node main.ts
```
